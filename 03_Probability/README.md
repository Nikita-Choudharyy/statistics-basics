# 🎲 Probability for AI/ML

Welcome to the **Probability** module of the **Statistics for AI/ML** repository.

Probability is one of the most important foundations of Statistics, Data Science, and Machine Learning. It helps us understand **uncertainty, randomness, events, relationships between events, and predictions based on available information**.

In this module, we move from the basics of Probability to more advanced concepts such as **Conditional Probability, Independence, and Bayes' Theorem**, while continuously connecting the concepts to real-world Data Science and Machine Learning applications.
